GitHub integracija
GitHub žeton se shrani samo lokalno v tvojem brskalniku (localStorage) in se uporablja za neposredno objavljanje na GitHub preko API-ja. Uporabi fine-grained token in mu omogoči Contents → Read and write samo za ta repozitorij.

Tokena ne vpisuj v HTML kodo. Vnesi ga samo tukaj.
